# Analysis

The reference format is a faceless infographic explainer, not generated camera footage. Its retention comes from semantic synchronization: each narrated claim changes one central visual world; a persistent headline and bottom caption stabilize the hierarchy; illustrated objects retain state long enough to understand; a CTA or quiz changes the viewing task near the end.

Hypit owns the named speech beats, picture direction, and their order. Remotion owns deterministic layered illustration, object choreography, layout, stable captions, and final encoding.
