# 14_8bit · 1985 8-bit pixel game

## Pipeline
1. **Everything is drawn on a 240×135 low-resolution canvas** (1 low-res pixel = 8 screen pixels; the original's pixel blocks measured 8px), then upscaled 8× in one `drawImage` with `imageSmoothingEnabled=false`.
2. **Background drawn per pixel with `fillRect`** (cached `8b_bg`): cross-dot wall = 6px grid, 3×3 crosses offset 3px on alternate rows; wooden floorboards y=106–113, a black seam every 24px; bricks 16×6 + 1px seam, offset 8 on alternate rows, one row of cream highlight along the top and left edges (`#fbe2a6`). The sky in the window in 3 blues (`#0856ef / #47c4f8 / #aae9fb`), with `(x+y)%2` checkerboard dither in the ±0.05 band at each boundary — the only way the NES ever did gradients.
3. **Characters = RIG paths scaled down to low res and filled → spriteize**: each part on its own layer (far arm / body+legs / hair / face / bangs / near arm; cat body / cat head), each layer:
   - `getImageData` → alpha < 110 straight to transparent (kills anti-aliasing) → the rest quantised to the 14-colour character palette (nearest colour);
   - outline 1px black (paint black any transparent pixel that has an opaque 4-neighbour).
   **Per-layer outlining is the key**: outlining the overall silhouette only once leaves hair/face/arm smeared into one blob; outlining each part separately gives the interior contours of an NES sprite.
4. **All facial features plotted pixel by pixel** (eyes 1×2 black + brows, cat eyes 2×2 black + 1 white highlight top-left, pink nose 1px, blush 2×1), positioned with RIG anchors `/8`, rounded.
5. **The mug does not use RIG.drawCup**: an AA path scaled to 6px wide goes mushy; draw a 6×5 white cup + two red bands + 3px handle directly at low res, following `G.cup`.
6. **HUD drawn at full resolution**: `PressStart2P` 48px (1 font pixel = 6 screen pixels; 64px is too wide and WORLD 1-1 collides with the apple icon), 8px black drop shadow; the cat-head/heart/apple icons are string bitmaps, 8×8 per cell.

## Jeans
RIG.girl wears a long skirt; the 8-bit version draws blue jeans with two `RIG.taper` segments (hip `G.hipSeat`→knee (1222,724)→ankle (1214,872), widths 92/76/56), far leg one step darker `#0838a8` and offset back 26px; white sneakers + one red stripe.

## Small loops (only ~0.23s ≈ 11 visible frames on screen, all done as stepped animation)
- Cat tail: 15fps four-pose loop `[-0.55, 0, 0.55, 0]` (RIG.cat's tail parameter), the "several drawings alternating" of pixel animation.
- HUD heart blink: lt 0.16–0.23 (≈ frame 630) swaps every 2 frames: full heart turns white, empty heart turns full red.
- Potted plant shake: leaf offset by whole pixels `[0,1,0,-1]` in the same window.
- Question block pops out a coin: lt 0.06–0.22, half-sine 9px up then back down.
- Cloud outside the window shifts 1px left over 2 frames; pixel steam, three columns of 1×2 dots, 1px up per frame at 30fps, 6px loop.

## Pitfalls hit
- The RIG cat's head tops out at y≈535 and covers the window sill (the window goes to y=590). That is the shared skeleton's position, so it wasn't moved; the 8-bit black outline makes the overlap more obvious, but transitions depend on the standard composition, so it stays.
- `spriteize` reads non-premultiplied RGBA — do not divide by alpha again.
- Performance: hot frames 2.5–6ms, cold start 11ms.
